# 《黄金四分钟》PRD —— 心肺复苏节拍训练游戏（第一版）

> 项目：零基础 AI 协作开发 · 新作品
> 作者：庄喻晴（广东医科大学）
> 日期：2026-11-10
> 定位：面向零基础学习者的急救科普训练游戏，也是「AI 协作开发方法论」的新教学样本

---

## 一、一句话目标

让一个没学过急救的人，在 3 分钟的游戏里**亲手按对 CPR 的节奏**，并记住「叫—压—电」三步。

## 二、为什么做（真实痛点）

- 院外心脏骤停的黄金抢救时间只有 4～6 分钟，救护车平均到达时间远超于此
- 现场立即 CPR + 3～5 分钟内除颤，存活率可达 49%～75%；什么都不做，每过 1 分钟存活率下降 7%～10%
- 看教学视频「看会了」≠ 按压节奏做对了。按压频率必须落在 **100～120 次/分**，快了慢了都无效——这件事只有「亲手按、被测量」才能学会
- 目标用户：大学生、新入职员工、社区急救科普活动

## 三、游戏流程（状态机）

```
TITLE → PHASE1 判断意识 → PHASE2 呼救 → PHASE3 按压节拍(30次)
  → PHASE4 吹气(2次) → [循环第2轮: PHASE3 → PHASE4] → PHASE5 AED → RESULT
```

| 阶段 | 玩家动作 | 判定 |
|------|---------|------|
| TITLE | 按 Enter 开始 | — |
| P1 判断意识 | 拍肩呼唤：连按 F 键 3 次 | 计时：从阶段开始到第 3 次按键 |
| P2 呼救 | 二选一：按 1（自己跑去打电话）/ 按 2（指定别人打 120、别人取 AED，自己留下按压） | 选 2 正确（不能离开伤员） |
| P3 按压 | 跟节拍按空格，共 30 次 ×2 轮 | 每次按压间隔判定（见四-1） |
| P4 吹气 | 按住 B 键，屏幕充气条到绿色区间松手，共 2 次 ×2 轮 | 按住时长落在 0.8～1.2 秒判定「吹气有效」 |
| P5 AED | 按提示顺序按键：开机(Enter)→贴片(1)→所有人离开(2)→电击(空格)→立即继续按压 | 顺序错则该步重做并记录错误 |
| RESULT | 显示评分，按 R 重玩 | — |

## 四、可量化的验收标准（全部可被测试脚本测量）

### 1. 按压节拍判定（核心）
- 目标频率：100～120 次/分 ⇒ 相邻两次按压间隔 **500～600ms 为「准」**
- 判定档位：
  - 间隔 500～600ms → **PERFECT**（+2 分）
  - 间隔 420～500 或 600～680ms → **GOOD**（+1 分）
  - 其余 → **MISS**（+0 分，且屏幕节拍器变红）
- 验收：输入任意间隔序列，分类函数输出与上表完全一致（测试脚本逐条断言）

### 2. 节拍引导
- 按压阶段播放节拍音：**110 次/分（间隔约 545ms）**，用 WebAudio 振荡器生成短哔声，不加载任何音频文件
- 验收：节拍音间隔误差 ≤ ±5ms（用脚本测 timer 记录值）

### 3. 评分公式
- 节奏分 = PERFECT×2 + GOOD×1，满分 120（60 次按压全 PERFECT）
- 流程分 = P1/P2/P5 各步首次即对得满分，满分 30
- 吹气分 = 4 次吹气每次 5 分，满分 20
- 反应分 = P1 用时 ≤3 秒满分 30；每超 1 秒扣 5 分，扣完为止
- 总分 = 节奏 + 流程 + 吹气 + 反应（满分 200）
- 等级：≥180 S；≥150 A；≥120 B；<120 C
- 验收：给定模拟成绩，总分与等级计算结果和公式一致

### 4. 技术规格
- 画布 480×320，16:10，CSS 放大 2 倍显示；逻辑分辨率固定，不随窗口变形
- 固定步长更新：1/60 秒；渲染与逻辑分离（沿用马里奥 v2 架构）
- 所有颜色收进 PALETTE 常量，禁止硬编码色值
- 键盘输入：Enter / F / 空格 / B / 1 / 2 / R；防止长按重复触发（keydown 只在首次触发）
- 零依赖：双击 index.html 即可玩，不联网、不装包

### 5. 教学模式
- `CONFIG.tutorialMode: true` 时，每阶段开始显示 1～2 行提示（讲「这一步在真实急救里为什么这么做」），首次 PLAY 后可在标题页关闭
- 提示位置不写死：由各阶段定义自己的提示文本锚点

### 6. 医学内容准确性
- 按压频率 100～120 次/分；深度 5～6 cm（画面文案）；按压:吹气 = 30:2
- 呼救要点：指定具体的人打 120、取 AED；施救者不离开伤员
- AED：开机→贴片→分析/电击时任何人不得接触患者→电击后立即继续按压
- 结果页与说明区标注：**「本游戏用于科普训练演示，不能替代正规急救培训」**

## 五、本期不做（明确排除）

- 不做手机触屏适配（键盘即可）
- 不做音效文件 / 背景音乐（只用振荡器哔声）
- 不做儿童/婴儿 CPR 参数（仅成人，文案注明）
- 不做账号、存档、排行榜
- 不做动画人物立绘（用简洁几何/像素图形表达）

## 六、验收方式

`node test-cpr.js` 无头运行，至少覆盖：
1. 节拍间隔分类（≥8 组边界值断言）
2. 评分公式与等级映射（≥5 组断言）
3. 状态机推进：正常流程 + P2 选错 + AED 顺序错三种路径
4. 30:2 循环计数正确（2 轮共 60 次按压、4 次吹气）

全部 PASS 才允许交付。
